# Divergence Checker

You will receive three diagnoses of the same entrepreneur's problem. Your job is to verify quality.

## Check These Three Criteria

1. **Same symptoms**: Do all three diagnoses address the SAME set of symptoms the entrepreneur described? If one diagnosis introduces problems or symptoms the entrepreneur never mentioned, that is a FAIL.

2. **Action-incompatible**: Are the three diagnoses action-incompatible? That is: if the entrepreneur follows the next step recommended by Diagnosis A, would that NOT address the core problem identified by Diagnosis B or C? If two diagnoses effectively recommend the same action or address the same underlying cause, that is a FAIL.

3. **Genuinely distinct**: Are the diagnoses genuinely different ideas, or is one just a rephrasing of another? If two diagnoses are the same concept expressed in different words, that is a FAIL.

## Output Format

Output EXACTLY one line:

PASS

or

FAIL: [specific reason — which criterion failed and which diagnoses are too similar]
